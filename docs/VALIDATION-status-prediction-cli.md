## 实际公开接口检查

上一阶段的 [macOS 工作流](https://github.com/yzin-17/codex-monitor/actions/runs/34509345609) 实际读取了 OpenAI summary、Observatory current 和 Will forecast 的公开 JSON，解析按实际结构实现。接口检查不包含任何账号、对话或密钥，不证明这些第三方接口未来保持不变。

## 必须保留的限制

- 真实 Codex 账号在系统浏览器完成授权、真实 CLI 恢复和 Desktop 同步仍需用户 Mac 验收；合成协议和原生截图不能代替实连。
- 续跑只支持原 CODEX_HOME 下的文件型 ChatGPT CLI 登录；不会从 Monitor 远程账号借用凭据，也不支持 API Key、自定义 openai 路由或缺失的会话配置。
- 默认 read-only；用户明确同意且原会话允许时可选 workspace-write。网络与额外写目录保持关闭，不放宽原审批。
- 每个额度事件至多发起一次；发送结果未知不自动重试。应用锁只能防止 Monitor 重复分发，不能消除用户同时在 Desktop 继续的最后瞬间竞争。
- Monitor 不直接改写 Codex 登录文件；用户授权启动的官方 CLI 仍可能按自身机制更新登录材料和会话记录。退出 Monitor 会停止它启动的 CLI，已执行操作不回滚。
- 预测、公开状态和邮件均不会触发执行。重置卡到期、社区重置事件与个人额度恢复是不同含义。
- 多屏、真实菜单栏、连续动画与长期资源占用尚需实机确认，安装包未做 Apple 公证。
