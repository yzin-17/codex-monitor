# Codex Monitor 首版规格

日期：2026-09-10

## 目标

新建独立原生 macOS 项目，满足对话级 Token、父子代理拆分、Skills 本地证据分析，避免网页登录、远程账号和额外模型调用。源码可维护、可单独验证，不继承两个参考仓库的整个实现。

## 架构

`SwiftUI / AppKit → AppStore → AnalysisEngine actor → Scanner / Index / SkillCatalog → LedgerMath / Reports`。

核心无 GUI 依赖、无网络、无执行 Shell 的能力。系统 SQLite 作为只读元数据源，扫描结果缓存使用本应用私有目录的 JSON；首版不为了数据量未验证的场景提前扩展复杂数据库状态机。

## 首版交付

概览、对话与子代理、Skills、设置与隐私四页；菜单栏汇总和可拖动浮动条。增量扫描与半行恢复、保守累计归属、父子聚合、Skill 证据、脱敏报告与本地价格表。

## 不包含

网页 Analytics、自动读登录态、实时账户 API、自动追踪 Codex 选中窗口、自动修改 Skill、可靠执行质量打分、精确逐 Skill Token、移动端和远程多账号。不得用演示数据代替真实数据且不标注。

## 验收

核心测试在合成脱敏日志上验证；桌面必须在 macOS 编译并验收。首次真实数据验收至少抽样一个父子任务、一份归档、一段跨日累计与一个 Skill 读取事件，记录差异，不上传真实数据。

## 风险

JSONL 及 state 数据库结构会演化；版本不匹配需明显显示诊断。巨大日志预算是分片预算而非全部操作实时上限。缺少上游公开账单细节时，成本只是参考值。已通过 GitHub macOS ARM64 CI 的 GUI 编译与打包，但真实桌面交互和数据兼容仍不能视作已完成验收。
