# 紧凑监控面板 UI 重做

日期：2026-09-10

## 目标与边界

以用户本次提供的截图为视觉参考，替换原有宽侧栏／左右分栏。独立实现界面，不复制第三方源代码。保留离线、无登录、只读数据和 Skills 能力；不因为右侧参考图存在 Codex Radar 就引入网络数据源。

## 界面

- 主窗口默认 760 × 744，最小 640 × 660。近黑背景、炭灰表面、细边框、14 pt 圆角，绿色仅用于运行和额度，青色辅助证据展示。
- 顶部 390 × 44 胶囊 HUD，依次显示日志运行状态、5h／7d 快照和今日 Token；真实数据不与演示混淆。
- 标题行右侧刷新与设置。全宽分段标签仅 Codex / Skills，不再占用左侧导航列。
- Codex 页：额度卡 → 密集会话表 → 今日／7天／30天统计条。表格按运行优先，显示 Session、Status、Today 与 Total；点击用 sheet 展示父、子、合计与模型细节。
- Skills 页：证据卡网格 → 解释条 → 最近证据表 → 汇总条。卡片数值为读取返回成功次数，绝不伪造 Skill 评分或消耗。设置和用量构成收进按需打开的详情。
- 菜单栏弹出同一套面板；浮动条可拖动、点击打开主面板、右键隐藏。

## 可信状态

运行状态来源仍为日志。超过 10 分钟未更新为 STALE；缺失时间／未知事件为 UNKNOWN；不能伪装成可靠的进程 RUN/IDLE。额度仅选择通用 codex 桶；缺少记录或快照重置时刻已过显示 —，不填 100%。底部持续标明本地快照、时间和回填状态。

今日占比的分母为本地自然日已扫描用量。任务行包含所有已识别子代理，与今日汇总对账；累计 Total 不受日期过滤。导出、价格、隐私、来源定位、项目和目录配置能力仍保留。

## 验证

新增纯展示投影测试。macOS CI 编译原生界面，并从真实 SwiftUI / AppKit 组件渲染五张合成截图：Codex、Skills、最小尺寸、HUD、空状态。截图命令不读取用户配置或日志、不启动扫描器。截图能证明布局渲染，不代替浮动条拖动／菜单栏／文件选择等交互实机验收。
