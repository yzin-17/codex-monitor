# 放大展开面板与对话费用明细

日期：2026-09-10。状态：实施中（T09、T10、T11 本地实现完成，T08 真实运行态复验待执行）。基线：`54c7cfab87587ab808ea5f48b75faede880c6182`，ALight 原版加 Jackie 扩展。

## 目标与边界

保留原版主界面和全部功能，在原生展开面板内扩大可读面积；点击对话行展开主代理、每个已识别子代理以及 Skill 关联费用。不得切回旧的独立重写版本，不新增主窗口或联网数据源。

## 展开几何

展开面板默认目标 680 × 720 个 macOS 逻辑点，宽高受当前屏幕、Dock 可用区和 12 点边距限制。原版内容采用 1.4 倍矢量布局缩放，字号、按钮和内容区域一起增大；外部 NSPanel 与内部 SwiftUI 使用同一尺寸计算。紧凑刘海、标准/窄刘海物理尺寸不变。主区域内容超高时滚动，主面板不向屏幕底部无限增长。四个主标签以及可选远程标签继续保留。

## 对话行

标题与副标题区域成为展开按钮，右侧原有 Token 构成弹窗保留独立按钮。一次展开一个对话；切换主标签或收起面板时取消明细扫描。展开区按层级显示主代理和全部已识别后代代理，不把 Fork 当子代理。金额为沿用原版价格表的 API 等价估算，不等于订阅实际扣款。

明细合计只累计每个代理自身的日志用量。相同会话的归档副本去重。子代理日志只在从父历史进入子代理自主执行的首次归属边界清除继承用量；同一代理 ID 后续因 `compacted`、`world_state` 或续跑形成的计数连续区间必须合并，不得再次清空已经确认的费用。压缩前后重复的累计值通过高水位去重；累计回退时保留此前确认的合计，将无法确认的后续增量标记为缺口而不猜测。不同代理 ID 保持独立明细，只在任务合计中汇总。

子日志尚未追平目标文件大小之前，其费用状态为“扫描中”，不与“已追平但没有 `token_count`”混为一谈。未知模型、缺失 Token 构成和累计缺口不猜价。列表快速快照与按需明细范围可能不同，出现差额时同时显示两个 Token 值和说明，不伪造完全对齐。

## Skill 口径

只有至少一条 Skill 费用具备可归属证据时，才显示“Skill 关联回合费用”，且不称为精确的独立 Skill 账单。没有可归属行、Skills 已关闭或全部证据不可读取时，整段 Skill 费用区域及其专属空状态、专属缺口提示均不渲染，不显示为 0 美元；代理通用缺口文案也只说明未猜价，不残留 Skill 归属说明。只有简单文件读取/支持的结构化读取有 call_id 配对成功信号、且同回合存在用量记录时，才建立关联。仅提及名称、读取尝试、读取失败、助手自称使用均不形成费用归因。

每个 Skill 显示关联回合数、代理数、Token 和估算金额。金额涵盖该回合的所有模型请求，不是读取文件本身的边际成本。多个 Skill 同回合时会重叠，禁止相加，禁止再次加入主/子代理合计。没有证据时显示不可归属而非 0 美元。按规范文件路径区分同名 Skill；生效状态不由路径存在推断。

当前读取命令支持简单 cat/head/sed、rtk cat 或 rtk proxy 包装，以及显式文件路径的 read_file/skills_read。复合 shell、Python 自定义读取、无明确结果的工具调用不猜测。要求 task_started 或带 turn_id 的 turn_context 提供回合边界；旧格式没有边界时仅有代理用量，没有 Skill 费用。暂不扩展既有 Skills 周报数据库。

## 扫描生命周期、性能与隐私

列表刷新不触发明细分析。展开时后台按需读取，不设置累计字节数或累计时长上限，持续扫描到已发现代理日志均追平本轮观察到的目标文件大小。实现必须使用有界工作片、轮转未完成代理、回收提前完成代理的剩余预算，并在工作片之间检查取消和主动让出执行权；文件枚举、读取与 JSON 解析不得在主线程执行。

界面显示发现阶段、已扫描字节、目标字节、百分比和当前代理。进度更新应节流，主线程只接收聚合后的状态。运行中日志增长时扩展目标并继续读取；追平某一时刻的文件末尾后可以显示“已追平，等待新记录”，不得因日志仍可能增长而永久显示未完成。

扫描游标和聚合器按任务保存在有界的内存缓存中，收起再展开应从原位置继续；明确刷新、文件替换、截断、身份变化或缓存淘汰时才重建。缓存不落盘保存命令、正文或工具输出。扫描使用原版解码器、Jackie 分片读取器和原版价格表；不执行任何日志中的命令，不读取 auth.json，不发送网络请求。

## 验收标准

- AC1：同一子代理在首次归属边界之后跨多次 `compacted/world_state` 的用量连续合并；重复累计值不重复计费，后续压缩不清空既有合计。
- AC2：不同子代理 ID 保持独立行；父历史、Fork 和无法确认归属的记录不计入子代理费用。
- AC3：扫描没有累计总量上限，能够在后台持续到追平目标文件大小；未完成代理轮转使用可回收工作片，主线程保持可交互并支持及时取消。
- AC4：界面持续显示发现或扫描进度，并区分“扫描中”“已追平但没有用量”“存在缺口”“已追平等待新记录”；能够从有限前缀确认外层类型且不承载费用证据的超大 `compacted` 行可安全忽略，不得仅因该行超过解析上限而误报缺口。
- AC5：收起再展开保留内存游标；明确失效条件会安全重建，不新增日志正文持久化、命令执行、凭据读取或网络请求。
- AC6：覆盖大/小屏、负坐标副屏、四主标签、行内展开和 Token 弹窗独立点击。数据回归覆盖父子孙、Fork、归档去重、继承边界、跨压缩累计、未知价格、长上下文、Skill 多重关联、失败读取、半行、截断、取消及符号链接边界。
- AC7：没有任何可归属 Skill 费用时不渲染 Skill 费用区域和 Skill 专属诊断，代理通用诊断也不出现 Skill 归属说明；存在可归属行时继续显示已有行，局部证据缺口仅作为该区域内的说明。
