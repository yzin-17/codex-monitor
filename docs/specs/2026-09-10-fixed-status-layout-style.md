# 固定运行状态、统一外观和布局控件

日期：2026-09-10。基线：0.3.0；交付版本：0.3.1。

## 目标与边界

左侧始终保留本机 Codex 运行状态灯和 RUN/IDLE，右侧才是可编辑区域。切换到其他 Codex 账号、网关或清空布局，不能改变或移除左侧状态。继续基于 ALight/Jackie 当前实现，保留性能、Skills、Radar、账户、代理费用和从 HUD 展开的动画；不引入其他供应商，不执行源码哈希检查。

## 显示与外观

显示模式和刘海几何合并成一个设置区；只有实际使用刘海模式时展示物理刘海微调和两侧尺寸。几何选项也即时生效并同步原设置草稿。非刘海模式仍是覆盖菜单栏的 NSPanel，固定状态获得优先空间，只有右侧内容可被裁剪。刘海遮挡区保持物理屏幕中心，右侧根据自定义内容分配宽度。

采用原项目 MonitorTheme 的灰色标签、浅白数值及绿/橙/红额度状态色。删除 HUD 背景的 behindWindow/hudWindow 材质，改回中性黑色透明底，默认浓度 0.985。只迁移上一版默认的 0.30/0.78 浓度，其他用户自定义值保留。透明度主动调低时会正常透出底下桌面，这不等于应用添加蓝色主题。保留原字号，不增加整体 scaleEffect。

## 右侧布局

支持重复空格（2–48 pt）、分隔点、点击添加、按位置拖动/移除、跨行移动、最多两行、每行最多 12 个控件、来源覆盖、预设及仅显示左侧状态。旧字符串行配置可直接读取，旧 state 条目迁移出自定义区域，空格实例按位置操作，不能一次误删所有空格。

参考 CodexBar 固定快照 7fdc17636f161ab410d8a6a0e8f45b6a595cf8d2 的 MenuBarLayoutToken 类型，保留图标/名称/账号、会话/每周/范围每周/自动百分比、第一/第二/第三额度、节奏、用量条、自动和显式窗口重置、预计用尽及紧凑形式、余额/今日/30天费用、空格/分隔点和条件显示类型。隐藏可用于条件分支。额外保留本项目今日 Token。

条件控件可编辑最多 8 个比较条件、AND/OR、已用/剩余、阈值、满足与否则的显示控件；规则缺数据时显示未知而非误选分支。条件不能递归或控制固定运行状态。节奏按本窗口已用比例减去已过时间比例计算，预计用尽按本窗口平均使用速度估算；缺少真实窗口长度、重置时刻、有效数值，刚开窗或读取过期时显示 —。控件类型兼容不代表照搬 CodexBar 所有供应商的数据。

## 验收

验证固定状态与右侧账户独立、状态不在控件列表、重复空格操作、配置迁移、条件未知值、额度配色、两行高度、窗口中心遮挡位置和原有页面。原生截图只能验证静态布局，不替代动画和真实账户实机验收。
