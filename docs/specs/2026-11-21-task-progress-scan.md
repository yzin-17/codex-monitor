# 任务清单扫描状态与变更等待

## 范围与约束

修复任务行、清单浮窗与文档管理中的扫描状态，以及自动发现调度。保留 Markdown 绑定、候选来源、忽略规则、文档同步和手动重扫。本次不增加新的清单来源，真实会话日志保持只读。用户后续明确授权与测速修改一并提交、推送 tag，并安装本机 `0.4.14`；真实账户和长期运行验收独立记录。

## 验收标准

- AC1：扫描中使用加载动画；未关联使用清单图标和明确文字；已知任务进度使用圆环与计数。未知或部分数据不显示虚构百分比，错误与缓存语义保留。
- AC2：扫描追平后，相同输入的轮询、重新展示与无关事件不重新扫描；日志、已发现文档、项目任务目录变化或手动重扫可触发发现。目录新增、文件缺失后恢复均可被识别。
- AC3：超大日志分段续读不因输入未变化而中断；展示读取进度和待续读状态。停止后撤销扫描状态，旧工作结果不能覆盖新状态。
- AC4：合成数据回归、`scripts/test.sh`、`scripts/build.sh` 和原生截图验证通过；检查原有 Codex、性能、Skills、Radar、远程开关和清单三个页签。截图不代表安装后真实账户验收。
