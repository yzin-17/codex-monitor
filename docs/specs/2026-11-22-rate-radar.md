# 最近请求测速与 Radar 发布标识兼容

## 范围

修复运行中最近请求速度的显示，以及公开当前总榜已完成发布的兼容读取。原始会话日志只读；真实数据诊断与合成测试分开。用户已授权测试、构建、提交、推送 tag、本机升级、退出旧版及删除安装备份。

## 验收标准

- AC1：RUN 时保留当前活动会话及其子代理的最近有效请求速度；工具等待或样本不再新鲜时置灰，确实无样本时显示 `— token/s`，IDLE 时隐藏。新鲜并发样本继续按独立输出合计，历史样本只展示最近一次，不累加。其他会话、内部审查、未来及无效样本不进入测速。
- AC2：接受 `codex-four-accepted-complete/1` 和 `codex-four-accepted-event/1` 的完整公开总榜；继续验证 schema、计分协议、权重、完成状态、样本数量、模型配置唯一性及各项分值。未知发布标识与不完整数据仍拒绝，保留成功缓存。
- AC3：合成回归覆盖等待／过期／无样本／空闲／并发和外部会话隔离；Radar 覆盖两种完整发布标识、未知标识、不完整数据及缓存恢复。完整测试、原生截图、双架构构建和独立回归通过，公开接口验证独立记录。
- AC4：版本入口同步为 `0.4.16`，本轮改动合并提交并推送 `main` 与 `v0.4.16`；更新 `/Applications/CodexMonitor.app`，验证版本、签名与进程，退出旧版并删除本次安装备份。真实使用效果与 CI 分别报告。
