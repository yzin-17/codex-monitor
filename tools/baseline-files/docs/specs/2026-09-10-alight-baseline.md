# ALight 基线纠正规格

日期：2026-09-10。

## 目标与范围

以 ALight 原项目固定版本为实际基线，完整保留样式、交互、统计、Radar、远程账号及设置。只增量接入 Jackie 的性能与 Skills；不再使用独立重写的核心与 GUI。旧代码保留在备份分支。

## 新增集成

主标签为 Codex、性能、Skills、Codex Radar，远程账号/NewAPI/Sub2API 按原版设置显示。Radar 未启用时呈现未启用状态，不把假数据当成联网结果。性能页面可见时采样，后台采样需主动开启；Skills 关闭时取消分析与计时器。追加两个设置开关，沿用原保存逻辑。

## 数据、安全与来源

保留原版父子代理汇总及费用口径。Skill 证据与效果分开，不提供逐 Skill 费用假归因。隔离应用、Keychain 和派生目录，保留来源哈希、原有版权文本与历史；许可不明部分不自行授予许可。安装不得关闭系统保护，不结束 Codex 或其他监控应用。

## 验收

逐文件来源门禁；原版 Swift Testing 与独立回归；新增性能/Skills/设置与截图测试；ARM64、Intel 编译打包与签名校验。截图来自真实 SwiftUI 的合成数据，不代表实机交互或真实账号对账。四主页面都必须存在实际内容与服务接线，不得只是空标签。
